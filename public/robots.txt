# ── AI crawlers, named explicitly ─────────────────────────────────────────────
#
# The wildcard above already allows every one of these. They are named anyway,
# because a named directive is an unambiguous decision rather than a default that
# nobody looked at — and because several of these operators publish separate
# tokens for training, indexing and live user-initiated fetches, which are three
# different questions that deserve three answers rather than one silence.
#
#   GPTBot             OpenAI, training and retrieval
#   OAI-SearchBot      OpenAI, indexing for ChatGPT search
#   ChatGPT-User       OpenAI, live fetch of a page a user asked about
#   ClaudeBot          Anthropic, crawling
#   Claude-SearchBot   Anthropic, search indexing
#   Claude-User        Anthropic, live fetch on a user's behalf
#   PerplexityBot      Perplexity, indexing
#   Perplexity-User    Perplexity, live fetch
#   Google-Extended    Gemini grounding. This is the consequential one: blocking
#                      it removes the site from Gemini's answers and has NO
#                      effect on Google Search ranking. Allowing it is the whole
#                      point of the generative-search work.
#   Applebot-Extended  Apple Intelligence
#   CCBot              Common Crawl, the corpus behind many models
#   meta-externalagent Meta AI
#   Amazonbot          Amazon
#   Bytespider         ByteDance

# /admin is deliberately NOT disallowed. It already serves
# <meta name="robots" content="noindex, nofollow">, and a crawler has to be
# allowed to fetch a page in order to see that tag — blocking it here would
# leave Google free to index the bare URL with no way to learn it is noindex.
# Its data is gated behind /api/admin/login regardless.
#
# /api/ has no such tag and returns no-store JSON, so it is blocked outright.
